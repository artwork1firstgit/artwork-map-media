# Artwork Map — public social media delivery

This repository stores final social-media assets that must remain reachable by publishing platforms until delivery.

- No application source code or credentials are stored here.
- No GitHub Actions are used.
- Each published asset is immutable and grouped by editorial ID and revision.
- The reproduced artwork in F009 is in the public domain; the editorial layouts are published for Artwork Map's social distribution.

Operational records and credentials remain outside this public repository.
